# 3D Eye & Hybrid Contact-Lens Simulator

A fully client-side (no backend) 3D visualization of the human eye and a hybrid
refractive–diffractive contact lens for myopia/hyperopia and chromatic-aberration
correction. Ray tracing runs in the browser (`eyesim.js`, a JS port of the
validated Python `eyesim` engine).

Just two static files: `index.html` + `eyesim.js`. Open index.html via any static
host. Uses Three.js (from CDN) for the 3D scene.
